# Token Maker 字体选择器设计

日期：2026-08-02

## 目标

为首页 Token Maker 的“文字设置”增加字体选择器。现有默认系统无衬线字体继续保留，另外提供 10 种支持简体中文、英文和中英混排的免费开源字体。用户可以为每个文字图层单独选择字体，编辑画布与最终 PNG 导出必须使用同一字体。

## 使用场景

用户在首页编辑器上传图片、添加文字，然后输入中文、英文或中英混排内容。选中文字图层后，用户在“字号”和“文字颜色”之间选择字体；画布立即显示选择结果。下载单个 Token 或批量渲染时，导出结果保持相同字形。

## 字体目录

保留当前默认字体，并增加：

1. 思源黑体（Noto Sans SC）
2. 思源宋体（Noto Serif SC）
3. 霞鹜文楷（LXGW WenKai）
4. 马善政毛笔楷书（Ma Shan Zheng）
5. 站酷小薇 LOGO 体（ZCOOL XiaoWei）
6. 站酷快乐体（ZCOOL KuaiLe）
7. 站酷庆科黄油体（ZCOOL QingKe HuangYou）
8. 志莽行书（Zhi Mang Xing）
9. 龙藏体（Long Cang）
10. 刘建毛草（Liu Jian Mao Cao）

字体文件使用上游发布的未修改文件，并随项目本地托管。每个字体目录同时保留对应许可证文件。Google Fonts 字体采用其上游开源许可证；霞鹜文楷采用 SIL Open Font License 1.1。

## 方案与模块边界

### 字体目录模块

新增一个单一职责的字体目录模块，提供稳定字体 ID、CSS 字体族名称、中英文显示名称、文件地址、可用字重和回退字体栈。UI、预览和渲染器只通过该模块读取字体信息，不重复保存字体映射。

字体 ID 写入 `TextBox`，而不是保存文件路径或任意 CSS 字符串。数据边界只接受目录中已知的字体 ID。

### 本地字体加载

通过本地 `@font-face` 声明字体文件。浏览器只在某个文字图层实际使用字体时下载该字体，避免首页一次性下载全部中文字体。

导出前的现有资源预加载阶段同时收集当前作品使用的字体，并通过浏览器 Font Loading API 等待这些字体完成加载。任何所需字体加载失败时，导出返回明确失败结果，不允许静默使用回退字体生成错误图片。

### 文字状态与兼容

`TextBox` 增加可选的字体 ID。新文字默认继续使用当前系统无衬线字体，以保持现有行为。旧的 localStorage 数据和旧批量草稿没有字体 ID 时，也按默认字体处理，不要求破坏性迁移。

批量草稿的复制、相等比较和渲染状态继续复用 `TextBox`，并把字体 ID 纳入视觉状态比较，保证切换字体后批量任务能够识别变化。

### 控制面板

在选中文字后的设置卡片内，将“字体”下拉框放在“字号”和“文字颜色”之间。中文界面显示中文名称并附英文家族名；英文界面显示英文家族名。下拉框采用原生可访问 `select`，标签通过现有 i18n 系统提供。

选择字体只更新当前文字图层，不影响其他文字图层。不同图层可以使用不同字体。

### 预览与导出

DOM 文字覆盖层使用字体目录生成的 CSS 字体栈。Canvas 渲染器使用相同目录生成 `ctx.font`，从而让预览、单张导出、分享预览和批量导出保持一致。

对于只有常规字重的书法或艺术字体，渲染器使用该字体真实支持的常规字重，不依赖浏览器伪造粗体。思源黑体和思源宋体可以按目录声明使用对应字重。

## 错误处理

- 未知字体 ID：在字体数据边界回退为现有默认字体，兼容旧数据；新 UI 不允许产生未知 ID。
- 字体文件请求失败：导出失败并沿用现有导出失败路径，不生成使用错误回退字体的 PNG。
- 浏览器不支持 Font Loading API：默认字体仍可导出；选择了本地字体时明确判定无法完成字体预加载。
- 字体许可证或文件缺失：构建前测试失败，不允许发布不完整字体目录。

## 修改范围

允许修改：

- 首页编辑器文字类型与默认值
- 字体目录及本地字体资源
- 文字设置控制面板与中英文文案
- DOM 画布文字预览
- Canvas 文字渲染与导出资源预加载
- 批量草稿的字体状态比较
- 与上述路径直接相关的测试

不修改：

- Coat of Arms 页面及其字体系统
- 图片、边框、遮罩和预设行为
- SEO 内容、导航和分享页面设计
- CSP、远程字体域名、部署配置
- 未关联的 UI 样式或代码重构

## 验收标准

1. 首页添加文字后出现字体下拉框，包含默认字体和 10 种已批准字体。
2. 同一个文字图层输入中文、英文或中英混排时，切换字体能改变实际字形。
3. 每个文字图层独立保存字体选择。
4. 刷新页面后，localStorage 中已保存文字的字体选择可以恢复。
5. 没有字体字段的旧文字继续按当前默认字体显示。
6. 单张 PNG、分享预览和批量导出与编辑画布使用相同字体。
7. 字体加载失败时不生成错误字体的导出文件。
8. 中英文界面均有正确的字体标签，不产生水平溢出。
