Token Maker Chrome Extension Privacy Policy

This page covers the Token Maker Chrome extension only. The Token Maker website is a separate product and has its own policy at tokenmaker.one/privacy.

What the extension does

Token Maker is a Chrome side-panel editor. You upload a local image, choose a bundled border, adjust pan and zoom, and export a PNG token to your computer.

What data we collect

The extension does not collect, store, sell, or transfer user data. There is no account, no analytics, no advertising, and no remote API for images or editor state.

  • Uploaded images stay in the extension’s local memory while you edit.
  • Exported PNG files are saved on your computer with a local download.
  • Closing the side panel discards the current editor session.
  • We do not upload your artwork to Token Maker servers.

Permissions

The extension requests only the sidePanel permission so the Chrome toolbar icon can open the editor. It does not request access to website content, browsing history, downloads, storage, or your tabs.

Third parties

The extension does not include third-party analytics, advertising, or crash-reporting SDKs. Chrome and the Chrome Web Store may process installation and listing data under Google’s own policies.

Children

The extension is not directed at children and does not knowingly collect personal information from anyone.

Changes

If this policy changes, the updated date at the top of this page will change. The current version is always published at this URL.

Contact

Questions or deletion requests: tokenmaker.one/contact

Token Maker Chrome 扩展隐私政策

本页只适用于 Token Maker Chrome 扩展。 Token Maker 网站是另一套产品，隐私说明见 tokenmaker.one/zh/privacy。

扩展做什么

Token Maker 是 Chrome 侧栏编辑器。你上传本地图片、选择自带边框、调整位置和缩放，然后把 Token 导出为电脑上的 PNG。

我们收集什么数据

本扩展不收集、不存储、不出售、不转移用户数据。没有账号、没有统计、没有广告，也不会把图片或编辑状态发到远程接口。

  • 上传的图片只留在扩展本地内存里，供当次编辑使用。
  • 导出的 PNG 通过本地下载保存到你的电脑。
  • 关闭侧栏后，当前编辑会话即丢弃。
  • 我们不会把你的原图上传到 Token Maker 服务器。

权限

扩展只申请 sidePanel 权限，用来在点击工具栏图标时打开编辑器。它不会申请网页内容、浏览历史、下载、存储或标签页权限。

第三方

扩展内没有第三方统计、广告或崩溃上报 SDK。Chrome 和 Chrome 应用商店可能会按 Google 自己的政策处理安装和上架数据。

儿童

本扩展不以儿童为对象，也不会故意收集任何人的个人信息。

变更

若本政策更新，页面顶部的日期会一并更新。现行版本始终发布在本网址。

联系

问题或删除请求： tokenmaker.one/zh/contact
