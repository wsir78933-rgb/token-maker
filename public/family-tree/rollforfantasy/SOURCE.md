# Family tree avatar source assets

These PNGs are from the public RollForFantasy Family Tree Creator asset root:

- Tool: https://rollforfantasy.com/tools/family-tree-creator.php
- Script: https://rollforfantasy.com/scripts/familyTree.js?rdwwwwqcwwiww
- Family tree styles: https://rollforfantasy.com/css/famTree.css
- Character layer styles: https://rollforfantasy.com/css/charBgs.css
- Source image root: https://rollforfantasy.com/images/npc/
- Local public root: `/family-tree/rollforfantasy/images/npc/`

`manifest.json` is generated by `scripts/download-family-tree-assets.mjs` and records every source URL, local URL, PNG dimensions, byte count, and SHA-256 after a successful download. `SHA256SUMS` is written only after every listed response has passed the PNG signature and IHDR checks. When another trusted fetcher has already placed the PNGs in the local root, `node scripts/download-family-tree-assets.mjs --verify-existing` performs the same checks offline and writes the complete manifest and checksum file without making network requests.

The manifest also includes the 17 `beard` files exposed by the source stylesheet as legacy selectors. The current UI and renderer use the color-indexed `beards` family for beard choices; the singular `beard` family is retained in provenance so the source stylesheet is not silently under-collected.

The source references 19 hair styles without a back layer (`1, 2, 3, 4, 6, 7, 8, 9, 10, 11, 12, 14, 15, 16, 19, 20, 21, 25, 31`) across all 16 hair colors. Those 304 URLs are recorded under `optionalMissingBackHair` with the observed redirect to `https://rollforfantasy.com/404.php`; they are intentionally absent from the local PNG directory and are rendered with the front hair layer only.

The source page normalizes every character layer to a 250×250 CSS box. The local renderer keeps that coordinate system and scales the complete layer stack into the requested UI box. The layer order is back hair, face, scars, beard, mouth, nose, eyes, eye wrinkles, face wrinkles, eyebrows, front hair, and ears. Face and eye wrinkle layers use source opacity `0.4`; multiple scars are emitted in ascending source index order.
