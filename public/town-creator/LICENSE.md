# 素材来源与使用说明

本包为这次委托独立绘制的正俯视矢量素材，交付给你用于项目开发、
修改、组合及地图导出。资源来源记录在 manifest.json 中。

所有素材由几何轮廓、线条和可重复纹理构成。没有包含 Roll for Fantasy
的原始 PNG、描摹轮廓或其脚本，也没有包含下载的第三方美术资源。
竞品调研只用于核对功能类别与基础素材覆盖。

本次交付没有替你为素材发布公共领域或开源许可。
你可以自行决定产品中的使用方式和对外分发政策。

制作使用本地 Python 标准库；PNG 渲染使用现有 sharp；
分类总览与图片检查使用现有 Pillow 和 numpy。
这些库不随本包分发。本包的素材文件不需要这些运行依赖。
