## 1. 正文承诺

- 读者点开后得到什么：能写出今晚官方怪物来源行——2014 **Kobold** 或 2024 **Kobold Warrior**——并只抄那一页的类型、阵营和战斗行。
- 最大已核验事实：同一 CR 1/8。2014 是 Small Humanoid、Lawful Evil；2024 Warrior 是 Small Dragon、Neutral；名字改成 Warrior。
- 本篇才并在一起讲的点：头词仍容易停在 2014 怪物页；2024 是另一张卡；日光范围加宽；Pack Tactics 按目标 5 英尺内未失能盟友来数。
- 绝对不能写：平均成一只“通用 kobold”；可玩特质 walkthrough；具名 VTT 世界已导入；最快/最佳/实测；Kobold 专用模板；产品能锁规则。

核心承诺（一个主意图）：**今晚这只 dnd kobold 不是两页的平均数；先锁年，再抄那一列。**

## 4. 两道检查（选定组）

选定：**方向 1**。

### 停留检查

目标读者是今晚要在 5e 桌上确认“kobold 是什么”的人，手里多半是仍在流通的 2014 CR 1/8 印象。看到 Matching CR 1/8 Does Not Make One DnD Kobold 会停，因为标题指出一个具体信息差：挑战等级对得上，并不等于同一只怪物。正文开篇第二句与锁年节“Matching challenge rating 1/8 is the trap”接得住。不是“有吸引力”空话。

### 适配检查

| 项 | 标题/描述用词 | 正文 |
|---|---|---|
| 数字 | CR 1/8 | 开篇、need-to-know、锁年段、Pack Tactics 节均有 challenge rating 1/8 与 CR 1/8 |
| 结果 | Does not make one | “Same challenge rating 1/8 does not make those one creature.” |
| 点名对象 | 找 dnd kobold 的桌 | ReaderTask 一致；不是职业优化玩家 |
| 方法 | Copy that page only | 开篇 “Write the source line, then copy that page only.” |
| 情绪 | 无灾难、无最佳 | 未夸张 |
| 描述承诺 | 2014 Small Humanoid Lawful Evil / 2024 Kobold Warrior Small Dragon Neutral | need-to-know 表与对照表 |
| 产品 | 无 | 未把 Token Maker 写进 Title/Description |
| 最高级 | 无 | 无 fastest/best/实测 |

备选 2 的改名事实正文有（“That rename is part of the lock”），但会让 2014 桌以为标题只谈 2024。备选 5 禁令正确，停留弱于 CR 信息差。
