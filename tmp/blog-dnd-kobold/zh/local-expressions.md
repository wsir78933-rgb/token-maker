不是英文 `dnd kobold` 的逐字翻译。

|---|---|---|
| **DND 狗头人** | 必做主查询有可读中文结果；灰机/百科/维基主名都是狗头人；本站其他种族文也用「DND + 中文桌叫法」 | **锁定主查询** |

## 写作时的用词约束

1. 主名写 **狗头人**。首次对照写 **Kobold**。不要用科博德。
2. 繁体来源可以注明「繁体资料写狗頭人」，正文用简体狗头人。
3. 神名优先跟灰机/资料站的 **库尔图马克**，并写明百科作克图玛，二者都指向 Kurtulmak。
4. 玩家特质必须跟锁的书走：瓦罗是摇尾乞怜 / 集群战术 / 日照敏感；魔邓肯是龙吼 / 狗头人遗产。
5. 外形争议用中文检索自己的话：叫狗头人、现在常画成带鳞爬行类、不要画成魔兽蜡烛鼠人或龙裔。
6. Token 用本站中文：**VTT Token**、需要时 **棋子**。不要把 token 写成中文主词。
